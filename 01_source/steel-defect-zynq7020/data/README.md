## 数据划分（已冻结，版本 `split_v1`）

| 集合 | 张数 | 每类 |
|---|---:|---:|
| train | 1,260 | 210 |
| val | 270 | 45 |
| test | 270 | 45 |

**划分方式**（冻结版本 `split_v1`；逐样本清单不随此候选发布）：

- 近重复判据：32×32 灰度双线性降采样后零均值归一化，取互相关 NCC；
  阈值 `τ = 0.98`；完全相同文件（SHA-256 相同）一律并群。
- 分群后**以群为单位**、**类内分层**分配到 train/val/test，从构造上避免该判据形成的同一分群跨集。
- 随机种子 `20261018`，`numpy.random.Generator(PCG64)`；70/15/15。

低阈值NCC跨集相似不能识别实体钢板来源，也不能单独证明或排除泄漏。
冻结分组判据及聚合划分是已记录方法，不将其扩展为“所有近重复风险已排除”的结论。
原始逐样本审计不随公开包发布。

## 预处理（已冻结，版本 `NEU_CLS_PREPROCESS_V1`）

```
8-bit 灰度 BMP（原图 200×200，不改原件）
  → PIL Image.BILINEAR 双线性缩放至 32×32（原图本就是正方形，无纵横比变形）
  → x = u8 / 255.0                        x ∈ [0, 1]
  → q = clip(round_ties_to_even(x / input_scale), -128, 127)
  其中 input_scale = 1/127 = 0.007874015748
       （仅用 **train split** 统计 a = max(abs(x)) 得到；val/test 未参与校准）
      input_zero_point = 0
```

**实测**：三个 split **零截断**（raw 最大恰为 127.0000），码值区间 `[0, 127]`。

> 像素恒非负 + 输入零点为 0 ⇒ 量化后只用到 INT8 正半区，负半区闲置。
> 这是对称量化 + zp=0 的数学后果，已在合同中记录。
